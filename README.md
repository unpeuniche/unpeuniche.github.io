## Projects

### [Crabigator - WaniKani Reverse Flashcards](crabigator/)

A minimal browser app for practising writing kanji and vocabulary from their English meanings (the reverse of WaniKani's default review direction).

**Features:**
- Fetches your WaniKani items via API (requires personal token)
- Random flashcards for writing practice
- Stroke-order animations for kanji
- Configurable level range and item type filters
- All data stored locally in your browser
